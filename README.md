# Complete Physiotherapy

Professional website for Complete Physiotherapy, a physiotherapy practice specializing in injury rehabilitation, sports performance, and musculoskeletal treatment in Augher, County Tyrone, Northern Ireland.

**Live Site:** [completephysio.co.uk](http://completephysio.co.uk/)

---

## 📋 Project Overview

Complete Physiotherapy is a modern, responsive website showcasing physiotherapy services and expertise. The practice is founded by David McCreesh, a highly experienced physiotherapist with a BSc in Physiotherapy and MSc in Sports and Exercise Medicine from Ulster University.

### Key Features

- **Responsive Design** – Mobile-first approach using Bootstrap 5
- **Professional Branding** – Clean, modern UI with teal color scheme
- **Service Showcase** – Detailed information about all physiotherapy services
- **Online Booking** – Integrated Cliniko booking system for client appointments
- **About Section** – Practitioner credentials and philosophy
- **Contact Information** – Multiple ways to get in touch
- **Social Media Links** – Instagram integration

---

## 🏥 Services Offered

1. **Physiotherapy** – Comprehensive assessment and individualized treatment plans
2. **Sports Massage** – Deep tissue massage for maintenance and recovery
3. **Online Physiotherapy** – Remote consultations and guided rehab
4. **Post-op Rehab** – Specialized rehab following surgery (sports surgeries, hip/knee replacements)
5. **Online Performance Training** – Performance and injury prevention training delivered remotely

---

## 🎯 Philosophy

The **COMPLETE Method** focuses on long-term health by:
- Addressing root causes rather than treating symptoms
- Understanding the client's past injuries, current concerns, and personal goals
- Creating tailored treatment plans
- Guiding clients from "Setback to Comeback"

## 💻 Development

### Local Development
To run this site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/[username]/CompletePhysio.git
   cd CompletePhysio
   ```

2. Open `index.html` in a web browser, or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   ```

3. Navigate to `http://localhost:8000` in your browser

### Making Changes
- Edit `index.html` for content changes
- Edit `style.css` for styling changes
- Replace image files (completephysiosign.jpg, davidphysio.jpg, david.jpeg) as needed
